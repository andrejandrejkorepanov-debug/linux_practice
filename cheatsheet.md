# Шпаргалка по Linux 
- ls -la(-ll): список файлов с правами
- cd: перейти в папку
- mkdir -p: создать папку, включая вложенные
- chmod 640: права владец rw, группа r, остальные ничего

## Git
git add файл - подготовить к сохранению
git commit -m "Что сделал" - сохранить версию
git push - отправить на GitHub
git stasus - что изменилось
git lig --oneline - история

## ssh-ключ для GitHub (делается один раз)
ssh-keygen -t ed25519 -C "почта" - создать пару ключей
cat ~/.ssh/id_ed25519.pub - показать открытый ключ (кладем на GitHub)
